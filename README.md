# ATALAYA
Recopilador centralizado de feeds de alertas tempranas en ciberseguridad y plataforma de monitorización continua.**  **ATALAYA** agrega, filtra y supervisa en tiempo real múltiples fuentes de inteligencia de amenazas (CERTs, boletines de seguridad, avisos de vulnerabilidades y feeds , para ofrecer visibilidad sobre incidentes y amenazas emergentes
