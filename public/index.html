Cada tema muestra las vulnerabilidades que lo mencionan en el titulo.
Regla: si el titulo de una noticia contiene un termino de esta lista y coincide con un tema, la noticia se descarta. Ejemplo: tema PHP + omitir ATTSILAN → "ATTSILAN ... PHP" se descarta. El contenido de la noticia no se revisa.
Formato: Nombre | URL. Para omitir un servicio del analisis y de la web, pon # al principio de su linea. Quita el # para volver a analizarlo.
Formatos (columna derecha):
• https://web.ejemplo.com → HTTP (codigo y latencia)
• 192.168.1.10:5666 o tcp://servidor:443 → TCP, comprueba que el puerto acepta conexiones (tipo Nagios)
• ping://10.0.0.1 o solo 10.0.0.1 → ICMP (ping)
Requiere que el monitor este activado: casilla General en Busqueda.
